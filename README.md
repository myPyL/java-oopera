# java-oopera

`java-oopera` - небольшое приложение для организации работы театра.

Что умеет приложение:
1. Создавать актеров, режиссёров, авторов музыки, хореографов
2. Создавать спектакли различных типов: обычный, оперный и балет
3. Распределять актёров по спектаклям.
4. Выводить на экран список актёров.
5. Заменять актёра в одном из спектаклей на актёра из другого спектакля.
6. Для оперного и балетного спектакля выводит на экран текст либретто.
7. Проверки:
 - исключает вероятность дублей, 
 - обрабатывает ошибку замены в спектакле несуществующего актёра.


**Используемые переменные:**
- `choirSize` - количество человек в хоре
- `choreographer` - хореограф
- `director` - режиссёр
- `duration` - длительность в минутах
- `height` - рост в см
- `librettoText` - текст либретто
- `listOfActors` - список актёров
- `musicAuthor` - автор музыки
- `numberOfShows` - количество поставленных спектаклей
- `title` - название спектакля
